# 株の売買判断ツール

yfinance から取得した株価データをもとに、テクニカル指標(移動平均クロス・RSI・MACD・ボリンジャーバンド)を
組み合わせて「買い / 売り / 様子見」を機械的に判定するWebアプリです。

**投資助言ではありません。** 表示される判断はあくまで参考情報であり、最終的な投資判断はご自身の責任で行ってください。

## 構成

- `backend/` — FastAPI アプリケーション
  - `main.py` — APIエンドポイントとフロントエンドの配信
  - `indicators.py` — SMA/RSI/MACD/ボリンジャーバンドの計算
  - `judge.py` — 指標を組み合わせた売買判断ロジック
  - `patterns.py` — チャートパターン(ダブルトップ/ダブルボトム/三尊/逆三尊)の検出ロジック
  - `pattern_api.py` — 複数銘柄をスキャンするパターン検出API
  - `universes.py` — スキャン対象のプリセット銘柄リスト
- `frontend/index.html` — 銘柄コードを入力してチャートと判断結果を表示する画面(Chart.js使用)
- `frontend/patterns.html` — パターンが発生しそうな銘柄を一覧表示するスクリーナー画面
- `tests/` — パターン検出のテスト(`python -m pytest tests`)

## セットアップ

```bash
pip install -r requirements.txt
```

## 起動

```bash
uvicorn backend.main:app --reload
```

ブラウザで `http://localhost:8000` にアクセスすると画面が表示されます。

## 使い方

1. 銘柄コードを入力します。
   - 日本株: `7203.T` (トヨタ自動車) のように証券コード + `.T` を指定
   - 米国株: `AAPL` のようにティッカーをそのまま指定
2. 取得期間を選択します。
3. 「判断する」を押すと、直近データを取得し以下を表示します。
   - 総合判定(買い / 売り / 様子見)とスコア
   - 各指標(移動平均クロス・RSI・MACD・ボリンジャーバンド)ごとの判定根拠
   - 株価チャート(移動平均線・ボリンジャーバンド付き)

## 判断ロジックの概要

各指標にスコアを付け、合計スコアでトレンドの強さを判定します。

| 指標 | 買いシグナル | 売りシグナル |
| --- | --- | --- |
| 移動平均クロス(25日/75日) | ゴールデンクロス(+2) / 短期線が上(+1) | デッドクロス(-2) / 短期線が下(-1) |
| RSI(14) | 30未満(売られすぎ, +1) | 70超(買われすぎ, -1) |
| MACD | シグナル上抜け(+2) / MACDがシグナルの上(+1) | シグナル下抜け(-2) / MACDがシグナルの下(-1) |
| ボリンジャーバンド | 株価が下限バンド以下(+1) | 株価が上限バンド以上(-1) |

合計スコアが `+2` 以上で「買い」、`-2` 以下で「売り」、それ以外は「様子見」と判定します。
しきい値は `backend/judge.py` の `BUY_THRESHOLD` / `SELL_THRESHOLD` で調整できます。

## API

```
GET /api/analyze?ticker=7203.T&period=6mo
```

- `ticker`: 銘柄コード(必須)
- `period`: `1mo` / `3mo` / `6mo` / `1y` / `2y` / `5y`(デフォルト `6mo`)

レスポンスにはOHLCV由来の指標履歴・総合判定・判定根拠が含まれます。

## チャートパターン検出(スクリーナー)

`http://localhost:8000/patterns.html` を開き、対象銘柄(日本株主要40銘柄 / 米国株主要30銘柄 / 任意の銘柄コード)を選んで
「スキャン」を押すと、以下のパターンが **形成中または完成直後** の銘柄をスコア順に一覧表示します。
行をクリックすると、パターンを構成する山・谷とネックライン・目標値をチャート上に表示します。

| パターン | 示唆 | 出力される進行段階 |
| --- | --- | --- |
| ダブルトップ | 下落 | 2つ目の山を形成中 / ネックラインへ接近中 / ネックライン割れ直後 |
| ダブルボトム | 上昇 | 2つ目の谷を形成中 / ネックラインへ接近中 / ネックライン突破直後 |
| 三尊(ヘッド&ショルダー) | 下落 | 右肩を形成中 / ネックラインへ接近中 / ネックライン割れ直後 |
| 逆三尊 | 上昇 | 右肩を形成中 / ネックラインへ接近中 / ネックライン突破直後 |

### 判定の仕組み

1. 過去1年の日足の高値・安値から、ZigZag で山と谷を抽出します。反転とみなす幅は銘柄の ATR(値動きの大きさ)から自動で決めます(画面の「感度」で調整可)。
2. 直近の山・谷の並びが各パターンの条件(山の高さの差3%以内、三尊の頭が両肩より高い、直前にトレンドがある 等)を満たすか判定します。底型は価格を上下反転して天井型と同じロジックで判定します。
3. 現在値とネックラインの位置から進行段階を決めます。ネックラインを割って(超えて)5営業日を過ぎたもの・目標値に到達済みのものは「発生済み」として除外します。
4. スコア(0〜100)= 進行度30 + 山(谷)の揃い具合25 + パターンの大きさ15 + 直前トレンドの明確さ15 + 出来高の減少15

しきい値は `backend/patterns.py` 冒頭の定数(`PEAK_TOLERANCE` など)で調整できます。

### API

```
GET /api/patterns/scan?universe=jp_major&min_score=50
GET /api/patterns/scan?universe=custom&tickers=7203,6758,AAPL
GET /api/patterns/detail/7203.T
GET /api/patterns/universes
```

- `patterns`: `double_top,double_bottom,head_and_shoulders,inverse_head_and_shoulders` から絞り込み(省略で全て)
- `stages`: `second_peak,right_shoulder,approaching,breakout` から絞り込み(省略で全て)
- `sensitivity`: 0.5〜2.0(大きいほど小さな波も検出)
- 4桁の証券コードには自動で `.T` を付与します。株価データは30分間キャッシュします。
