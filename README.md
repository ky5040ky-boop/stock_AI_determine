# 株の売買判断ツール

yfinance から取得した株価データをもとに、テクニカル指標(移動平均クロス・RSI・MACD・ボリンジャーバンド)を
組み合わせて「買い / 売り / 様子見」を機械的に判定するWebアプリです。

**投資助言ではありません。** 表示される判断はあくまで参考情報であり、最終的な投資判断はご自身の責任で行ってください。

## 構成

- `backend/` — FastAPI アプリケーション
  - `main.py` — APIエンドポイントとフロントエンドの配信
  - `indicators.py` — SMA/RSI/MACD/ボリンジャーバンドの計算
  - `judge.py` — 指標を組み合わせた売買判断ロジック
- `frontend/index.html` — 銘柄コードを入力してチャートと判断結果を表示する画面(Chart.js使用)

## セットアップ

```bash
pip install -r requirements.txt
```

## 起動

```bash
uvicorn backend.main:app --reload
```

ブラウザで `http://localhost:8000` にアクセスすると画面が表示されます。

## 使い方

1. 銘柄コードを入力します。
   - 日本株: `7203.T` (トヨタ自動車) のように証券コード + `.T` を指定
   - 米国株: `AAPL` のようにティッカーをそのまま指定
2. 取得期間を選択します。
3. 「判断する」を押すと、直近データを取得し以下を表示します。
   - 総合判定(買い / 売り / 様子見)とスコア
   - 各指標(移動平均クロス・RSI・MACD・ボリンジャーバンド)ごとの判定根拠
   - 株価チャート(移動平均線・ボリンジャーバンド付き)

## 判断ロジックの概要

各指標にスコアを付け、合計スコアでトレンドの強さを判定します。

| 指標 | 買いシグナル | 売りシグナル |
| --- | --- | --- |
| 移動平均クロス(25日/75日) | ゴールデンクロス(+2) / 短期線が上(+1) | デッドクロス(-2) / 短期線が下(-1) |
| RSI(14) | 30未満(売られすぎ, +1) | 70超(買われすぎ, -1) |
| MACD | シグナル上抜け(+2) / MACDがシグナルの上(+1) | シグナル下抜け(-2) / MACDがシグナルの下(-1) |
| ボリンジャーバンド | 株価が下限バンド以下(+1) | 株価が上限バンド以上(-1) |

合計スコアが `+2` 以上で「買い」、`-2` 以下で「売り」、それ以外は「様子見」と判定します。
しきい値は `backend/judge.py` の `BUY_THRESHOLD` / `SELL_THRESHOLD` で調整できます。

## API

```
GET /api/analyze?ticker=7203.T&period=6mo
```

- `ticker`: 銘柄コード(必須)
- `period`: `1mo` / `3mo` / `6mo` / `1y` / `2y` / `5y`(デフォルト `6mo`)

レスポンスにはOHLCV由来の指標履歴・総合判定・判定根拠が含まれます。
